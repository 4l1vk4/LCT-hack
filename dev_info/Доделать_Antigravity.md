### 2.5.5. Планирование бюджета (Критический пробел)
По ТЗ это одна из трех базовых образовательных механик:
1. До начала периода ребенок распределяет доступную сумму минимум по 3 корзинам: **Обязательные расходы**, **Необязательные расходы**, **Накопления**.
2. Контроль непревышения баланса и показ остатка:
   $$\text{Plan}_{mand} + \text{Plan}_{opt} + \text{Plan}_{sav} \le \text{AvailableBalance}$$
   $$\text{Remainder} = \text{AvailableBalance} - \text{Plan}_{total}$$
3. План утверждается до начала трат. По итогам периода отображается **сравнение Плана с Фактом**.
* ❌ **Текущее состояние в кодовой базе:**
  * Use Case написан (`ConfirmBudgetUseCase`), математика соответствия `calculateCompliance` написана (`PetEconomyCalculator.kt`).
  * **НО В ИНТЕРФЕЙСЕ ЭТОГО НЕТ!** В `CalendarScreen.kt` отображается только календарная сетка на 28 дней и пользовательские заметки-траты. Функция `BudgetCounterRow` объявлена, но не используется. Коллбэк `onConfirmBudget` никогда не вызывается. Ребёнок не проходит этап планирования личного бюджета.

## 4. Требования к сборке, RuStore и сопроводительной документации

### 4.1. Сборка для RuStore (ТЗ 3.3)
1. **Релизный подписанный APK:** В `app/build.gradle.kts` в блоке `buildTypes.release` включена минификация R8 (`isMinifyEnabled = true`), но **не настроен `signingConfig`** (нужен keystore, чтобы генерировался подписанный APK, готовый к установке экспертами без Android Studio).
2. **Карточка для RuStore (черновик):** В репозитории отсутствует файл с черновиком карточки (название, категория «Обучение/Дети», краткое/полное описание, возрастная маркировка 6+ и обоснование). В папке `pics` есть `app_icon_512x512.png`, но нет финальных скриншотов с устройства.

### 4.2. Документация репозитория (ТЗ 5)
По разделу 5 ТЗ проект оценивается экспертами по наличию обязательных документов. Сейчас в корне репозитория **отсутствуют**:
- ❌ `README.md` (назначение, состав, быстрый запуск, видеоссылка, APK).
- ❌ `ARCHITECTURE.md` (слои Clean Architecture, Room, MVI-потоки).
- ❌ `ECONOMY.md` (формулы баланса, настроения, сытости, очков эволюции, compliance).
- ❌ `COMPETENCIES.md` (матрица соответствия Единой рамке компетенций Минфина РФ).
- ❌ `TESTING.md` (результаты unit-тестов и отчёт о проверке на физическом Android-устройстве).
- ❌ Резервное видео демонстрации (до 3 минут, требование ТЗ 4.1).
